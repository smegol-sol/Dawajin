# اختبارات الشاشات — خارج `app/` عمدًا

كل ملف داخل `apps/mobile/app/` هو **مسار في شجرة التوجيه** بالنسبة لـ
Expo Router، بلا استثناء للاحقة `.test.tsx`.

اكتُشف هذا عمليًا لا نظريًا: بعد وضع اختبارات الشاشات بجوارها في `app/auth/`،
أظهر تفتيش مخرَج `expo export --platform web` أن `auth/login.rtl.test.tsx`
مسجَّل كمسار فعلي، وأن `@testing-library/react-native` صار **جزءًا من حزمة
الإنتاج** (مطابقتان في الحزمة).

لذلك تعيش اختبارات الشاشات هنا وتستورد الشاشة بـ`@/app/auth/login`.
`jest.config.js` يطابق `**/*.rtl.test.tsx` في كل الحزمة فلا يحتاج تعديلًا،
وفاحص `nav-coverage` يمنع عودة أي ملف غير مسار إلى `app/` (القرار #91).
